# ExPrograma3

Título do Projeto: Pak 47 - Man

Autores: Soumil Khulbe, Artur Mascarenhas, Pedro Alvim

Para rodar o jogo, baixe os arquivos no GitHub, abra-os no VS Code e execute o arquivo jogo.py. Após isso, o jogo será inicializado.

Link do vídeo:

A ideia por trás do nosso jogo foi adicionar mais um elemento de estratégia ao jogo clássico Pac-Man. As armas no jogo têm a finalidade de ajudar o jogador a criar novas oportunidades de atravessar o labirinto sem ser atacado pelos fantasmas. Cada arma possui uma função diferente, adicionando um elemento de aleatoriedade ao jogo, para que ele não fique repetitivo muito rapidamente.

Para rodar o jogo, tambem é presciso instalar o pygame, e verificar se o VS code esta na versao correta.
